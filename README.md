#Mini projeto

Mini-projeto desenvolvido no papel de **Desenvolvedor(a) Back-End .NET Júnior** de uma
rede de concessionárias. A aplicação é um **Console Application em C#** que recebe a
inspeção técnica de um veículo (Carro, Moto ou Caminhão), aplica as regras do
**Checklist de Vistoria**, calcula a pontuação final e emite o parecer de aprovação/reprovação.

# — Classificação final

| Percentual | Classificação | Ação corporativa |
|---|---|---|
| 90% a 100% | Aprovado com Excelência | Liberado para compra/revenda imediata |
| 60% a 89% | Aprovado com Apontamentos | Exige desconto na compra para reparos da oficina |
| 0% a 59% | Reprovado na Vistoria | Veículo recusado pela concessionária |

# Como rodar

``` 
cd src/AutoCheck.ConsoleApp
dotnet run dev 
```
